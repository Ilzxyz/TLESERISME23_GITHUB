◆ Cara tercepat (2–3 menit)

  1. Buka Pengelola File bawaan HP
  2. Masuk ke Android → data → id.tleserisme23.app → files
  3. Pindahkan tleserisme.db dari folder Download ke situ (pindahkan, bukan salin)
  4. Kembali ke sini, tekan Pasang sekarang

Kalau folder Android/data tidak bisa dibuka di HP-mu: taruh saja tleserisme.db di folder Download, lalu tekan Cari sendiri berkasnya. Cara ini jalan juga, cuma lebih lama (10–25 menit).
